Professor controls

Professors stay in control.

Source boundaries, difficulty level, answer style, strict mode, preview mode, and a correction loop — built so the avatar reflects the professor's standards.

Source boundaries

Class-only, approved public sources, or broader reasoning.

Difficulty level

High school, college, graduate, MBA, or custom.

Answer style

Socratic, direct explanation, quiz mode, exam prep, or roleplay.

Strict mode

When the source does not support an answer, the avatar says so.

Preview mode

Professors test the avatar before students use it.

Correction loop

Professors can flag weak answers and improve the source set.
